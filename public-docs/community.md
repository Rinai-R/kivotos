# Related projects

These projects are related to Kivotos and built by the community.

## Plugin directory

[kivotos.cafe](https://kivotos.cafe) is a community-run directory of Kivotos plugins. Listings are generated
from each plugin's public repository, so it is the fastest way to see what people are building and to
publish your own. It is independent of the Kivotos project and nothing on it is reviewed or endorsed by
us, so read a plugin's source before installing it.

## Tools and integrations

| Project                                                                                      | What it does                                                                                                                         |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Kivotos for VS Code](https://marketplace.visualstudio.com/items?itemName=hinnes.kivotos-vscode) | Opens the matching Kivotos project or worktree in VS Code and adds agent chat, file mentions, and editor links.                        |
| [VS Code Web plugin](https://github.com/itsjustanks/kivotos-plugin-vscode-web)                 | Opens a live Kivotos worktree in `vscode.dev` through a VS Code tunnel, including workspaces on headless hosts.                        |
| [Kivotos Icon](https://github.com/gpambrozio/kivotos-menubar)                                    | Shows workspace status across Kivotos hosts in the macOS menu bar and opens a workspace with one click.                                |
| [Kivotos Cross-Daemon Comms](https://github.com/xpufx/kivotos-cross-daemon-comms)                | Lets agents communicate with agents on another Kivotos daemon through an MCP server.                                                   |
| [Kivotos Antigravity ACP](https://github.com/tiezbro/kivotos-agy-acp)                            | Connects Google Antigravity CLI to Kivotos through ACP, with Kivotos-specific context, permissions, and concurrency handling.            |
| [Desvio](https://github.com/cleiter/desvio)                                                  | Rebuilds a personal fork from a set of branches, using an agent to resolve new conflicts and Git rerere to replay known resolutions. |

## Hosting and infrastructure

| Project                                                            | What it does                                                                                         |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| [Kivotos Self-hosted](https://github.com/blockfeed/kivotos-selfhosted) | Packages the Kivotos web UI and a local daemon as a Docker deployment.                                 |
| [Devbox Fleet](https://github.com/omrihaviv/devbox-fleet)          | Provisions and maintains per-developer GCP devboxes with Kivotos, coding agents, and Tailscale access. |
